Show HN: Quotestreak – Name that line. Beat your streak.

A trivia game with one mechanic: here is a line, where is it from. Movies and music, ten genres, four choices, build a streak. Speed round if you want pressure, leaderboard if you want a fight. No backend on the native apps, so it works on a plane. Web at quotestreak.heyitsmejosh.com, source on GitHub.
